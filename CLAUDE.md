# Project instructions

## Figures in data analysis

When you make any graph, chart, plot or image panel in this repository, follow
`figure_guide/FIGURE_GUIDELINES.md`. It has three tiers:

1. **Must** (research integrity, statistics, legibility): never break these.
2. **Defaults**: follow unless you have a better reason; state the reason in one line when you deviate.
3. **Freedom**: choose the representation, emphasis and layout that best fit the data. Do not settle for a generic chart.

Use `figure_guide/nfig.py` for final-size figures, panel labels, dot plots, CI lines, scale bars and
`nfig.check(fig)` before saving. Dependencies: `pip install -r figure_guide/requirements.txt`.

## Writing

For reports, README text, figure legends and any prose you write here, follow
`writing_guide/WRITING_GUIDELINES.md` (same three tiers: must / defaults / freedom).
