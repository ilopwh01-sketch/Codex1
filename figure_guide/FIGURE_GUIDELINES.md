# 연구 그림 지침 (Nature 수준)

데이터 분석에서 그래프·이미지를 만들 때 이 지침을 기본값으로 적용한다.
코드는 `figure_guide/nfig.py`와 `figure_guide/nature.mplstyle`를 쓴다.

> 규격 수치는 Nature 계열 저널에서 널리 쓰이는 기준을 정리한 **대략적인 값**이다.
> 투고 전에는 대상 저널의 최신 저자 안내(Figure guide)로 확인한다.

## 0. 빠른 시작

```python
import sys; sys.path.insert(0, "figure_guide")
import nfig

fig, ax = nfig.mosaic("ab;cd", width="double", height_mm=110)
nfig.dot_plot(ax["a"], {"Control": a, "Treated": b}, ylabel="Signal (a.u.)", error="sd")
nfig.panel_labels(ax)
nfig.check(fig)                      # 규칙 위반 경고
nfig.save(fig, "fig1", outdir="figures")   # PDF·SVG(제출용) + PNG(미리보기)
```

예시 전체: `python figure_guide/example.py` → `figure_guide/out/example.png`

## 1. 규격

| 항목 | 기준 |
| --- | --- |
| 폭 | 1단 89 mm, 1.5단 약 120 mm, 2단 183 mm. 처음부터 최종 크기로 그린다 |
| 글꼴 | Arial/Helvetica 계열 산세리프 하나 |
| 글자 크기 | 5~7 pt (최종 크기 기준) |
| 패널 라벨 | 8 pt 굵은 소문자 a, b, c, 왼쪽 위 |
| 선 두께 | 0.25~1 pt, 축선 0.5 pt |
| 해상도 | 사진은 최종 크기에서 300 dpi 이상 |
| 색 모드 | RGB |
| 파일 | 그래프는 벡터(PDF/SVG/EPS), 글자는 편집 가능한 텍스트로. 사진은 TIFF 등 무손실 |

## 2. 그래프

1. 패널 하나 = 주장 하나. 그리기 전에 그 주장을 한 문장으로 적는다.
2. **n이 작으면(< 20) 모든 데이터 점을 그린다.** 막대+오차막대(다이너마이트 플롯)는 쓰지 않는다 → `nfig.dot_plot`.
3. 분포 비교는 박스플롯·바이올린 + 점, 시간 경과는 평균선 + 95% CI 음영 → `nfig.line_ci`.
4. 상관은 산점도 + 회귀선 + `r`, `n` 표기.
5. 범례 상자 대신 선 끝에 직접 이름을 단다 → `nfig.label_lines`.
6. 축 제목은 `측정량 (단위)`. 위·오른쪽 테두리, 격자, 배경색, 그림자, 3D는 쓰지 않는다.
7. 막대그래프 y축은 0에서 시작한다. 로그 축은 명시한다.
8. 눈금은 3~5개, 바깥 방향.

## 3. 색

- 범주형: Okabe–Ito 팔레트(`nfig.PALETTE`). 같은 조건은 모든 패널에서 같은 색.
- 연속형: viridis/cividis. 양·음 값은 중앙이 흰 발산형(RdBu 등). **jet/rainbow 금지** (`nfig.check`가 경고).
- 빨강·초록 조합 금지. 형광 2채널은 마젠타·초록 → `nfig.merge_magenta_green`.
- 흑백으로 봐도 구분되는지 확인하고, 안 되면 마커 모양·선 스타일을 함께 바꾼다.

## 4. 통계 표기

- 오차막대가 SD / SEM / 95% CI 중 무엇인지 범례에 적는다 (`dot_plot`의 `error=`와 일치시킨다).
- n이 무엇의 개수인지(동물, 세포, 독립 실험) 적는다. 기술적 반복을 생물학적 반복으로 세지 않는다.
- 검정법, 단측/양측, 다중비교 보정을 적는다. 별표 대신 정확한 P값 → `nfig.p_text`, `nfig.bracket`.

## 5. 사진·현미경·젤 이미지 (이미지 무결성)

- **모든 이미지에 스케일바**를 넣고 길이를 그림이나 범례에 적는다 (배율 숫자 대신) → `nfig.show_image`.
- 밝기·대비 조정은 **이미지 전체에 선형으로**, 비교하는 이미지끼리 **같은 값**으로 적용한다. 그 값을 Methods에 적는다 (`show_image(..., log=list)`가 기록).
- 부분 보정, 지우기, 복제, 다른 이미지에서 잘라 붙이기 금지. 합성한 경우 구분선을 넣고 범례에 밝힌다.
- 비선형 조정(감마 등)이 꼭 필요하면 범례와 Methods에 밝힌다.
- 웨스턴 블롯·젤은 자르지 않은 원본을 보충자료(Source data)로 보관·제출한다.
- 원본 파일(현미경 원시 포맷, 원본 스캔)은 수정하지 않고 보관한다.
- 보간(interpolation)은 끈다 (`nature.mplstyle`에 설정됨).

## 6. 다중 패널 구성

- 읽는 순서대로 왼쪽→오른쪽, 위→아래로 a, b, c… 배치.
- `nfig.mosaic("aab;cde")`처럼 배치도를 먼저 정한 뒤 그린다.
- 패널끼리 축 범위·색·글자 크기를 맞춘다. 같은 변수를 비교하는 패널은 y축 범위를 공유한다.

## 7. 그림 범례(legend) 문장

1. 첫 문장: 그림 전체의 결론을 제목처럼 (예: "Drug A increases X expression.")
2. 패널별 설명: **a**, 무엇을 / 어떤 조건에서 / 무엇을 그렸는지.
3. 통계: 점·막대가 무엇인지, 오차막대 종류, n의 정의, 검정법, P값.
4. 이미지: 스케일바 길이, 대표 이미지라면 몇 번 반복 실험 중 대표인지.

## 8. 제출 전 점검표

- [ ] `nfig.check(fig)`가 경고 없이 통과
- [ ] 폭 89/120/183 mm 중 하나, 글자 5~7 pt
- [ ] 소표본은 개별 점 표시, 오차막대 종류·n·검정법이 범례에 있음
- [ ] 색각 이상 안전 팔레트, rainbow·빨강/초록 없음
- [ ] 모든 이미지에 스케일바, 조정값 Methods에 기록, 원본 보관
- [ ] 벡터 PDF/SVG의 글자가 편집 가능한 텍스트
- [ ] 합성(synthetic) 데이터나 예시 데이터가 실제 결과 그림에 섞이지 않음
