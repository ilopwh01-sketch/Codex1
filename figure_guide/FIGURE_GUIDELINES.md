# 그림 지침 (Nature 수준)

AI 채팅창이나 커스텀 지침에 그대로 붙여 쓰는 최종본이다. 이 저장소에서는 `CLAUDE.md`를 통해 자동 적용된다.
규격 수치는 대략적인 값이므로 투고 전에 대상 저널의 저자 안내로 확인한다.

```text
[그림 지침] 목표는 Nature 수준의 그림이다. 데이터가 말하는 결론을 독자가 한눈에, 정확하게 알아보게 만들어라.

1. 반드시 지킬 것 (예외 없음)
- 이미지는 전체에 선형으로, 비교하는 이미지끼리 같은 값으로만 조정한다. 부분 보정, 지우기, 복제, 숨긴 합성은 하지 않는다. 합성했다면 구분선을 넣고 밝힌다. 조정값을 기록하고 원본 파일을 보관한다.
- 현미경 사진에는 스케일바를 넣고 길이를 적는다.
- 그림 범례에 오차막대 종류(SD/SEM/95% CI), n이 무엇의 개수인지(개체·세포·독립 실험), 검정법, 정확한 P값을 밝힌다.
- 데이터를 왜곡하지 않는다. 막대그래프는 0에서 시작하고, 축을 자르거나 로그 축을 썼다면 표시한다.
- 최종 인쇄 크기(폭 89 mm 또는 183 mm)에서 글자가 읽혀야 한다(약 5~7 pt, 패널 라벨 8 pt 굵게).
- 색각 이상이 있어도 구분되어야 한다. 빨강·초록만으로 구분하지 않고, rainbow·jet 컬러맵은 쓰지 않는다.
- 예시 데이터나 합성 데이터를 실제 결과 그림에 섞지 않는다.

2. 기본값 (더 나은 이유가 있으면 바꿔도 된다)
- 소표본(n < 20)이면 개별 데이터 점을 보여준다. 막대+오차막대만 있는 그래프보다 점 + 평균 ± 오차막대를 쓴다.
- 산세리프 한 가지(Arial/Helvetica)를 쓰고, 격자·그림자·3D 같은 장식은 최소로 한다.
- 축 제목은 "측정량 (단위)". 범례 상자보다 직접 라벨을 쓴다.
- 범주형은 Okabe-Ito(#0072B2 #D55E00 #009E73 #CC79A7 #E69F00 #56B4E9), 연속형은 viridis 계열, 양·음 값은 가운데가 흰 발산형 팔레트를 쓴다.
- 그래프는 벡터(PDF/SVG, 글자 편집 가능), 사진은 무손실(TIFF)로 저장한다.

3. 자유롭게 할 것 (여기서 창의성을 써라)
- 이 데이터와 주장에 가장 잘 맞는 표현을 찾는다. 흔한 차트에 머물지 말고, 그 분야 최고의 연구자라면 어떻게 그릴지 생각한다.
- 강조할 한 가지를 정하고, 색·크기·배치로 시선이 그쪽으로 가게 한다.
- 다중 패널은 하나의 이야기(현상 → 기전 → 검증)가 되도록 구성한다.
- 모식도, 주석, 인셋, 작은 배수(small multiples) 등 필요한 장치는 무엇이든 쓴다.

4. 작업 방식
- 그리기 전에 이 그림의 결론을 한 문장으로 적고, 표현 방법 2~3가지를 짧게 비교한 뒤 하나를 고른다.
- 기본값을 깼다면 왜 깼는지 한 줄로 설명한다.
- 그림 범례는 첫 문장에 결론, 이어서 패널별(a, b, c) 설명, 통계, 스케일바 길이를 적는다.
- 완성한 뒤 까다로운 Nature 심사위원의 눈으로 다시 보고 고칠 점을 고친다.
```

## 코드로 적용하기 (Python)

`figure_guide/nfig.py`가 "반드시"와 "기본값" 항목을 코드로 처리한다. 표현 선택은 여전히 사람(또는 AI)의 몫이다.

| 지침 | 도구 |
| --- | --- |
| 최종 크기(mm)로 그리기 | `nfig.figure("single"/"double", height_mm=...)`, `nfig.mosaic("ab;cd")` |
| 패널 라벨 | `nfig.panel_labels(axes)` |
| 개별 점 + 평균 ± 오차 | `nfig.dot_plot(ax, groups, error="sd"/"sem"/"ci95")` |
| 평균선 + 95% CI | `nfig.line_ci(ax, x, reps)` |
| 직접 라벨 | `nfig.label_lines(ax)` |
| 정확한 P값 | `nfig.p_text(p)`, `nfig.bracket(...)` |
| 스케일바 + 조정값 기록 | `nfig.show_image(ax, img, um_per_px, scalebar_um, log=[])` |
| 마젠타·초록 병합 | `nfig.merge_magenta_green(ch1, ch2)` |
| 규칙 점검 | `nfig.check(fig)` (글자 크기, 폭, rainbow 컬러맵) |
| 저장 | `nfig.save(fig, "fig1", outdir="figures")` |

예시: `python figure_guide/example.py` → `figure_guide/out/example.png` (합성 데이터)
